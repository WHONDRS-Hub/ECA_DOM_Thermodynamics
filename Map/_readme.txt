To recreate the map, download the layers from the sources below and put each into a folder with the name matching the bullet. 

- HUC2_CONUS_Only
	https://www.hydroshare.org/resource/55b4b0d910964c8690252518c2e60f9e/
- NEON_Ecoregoins_CONUS
	https://www.neonscience.org/data-samples/data/spatial-data-maps
- cb_2018_us_state_20m
	https://www2.census.gov/geo/tiger/GENZ2018/shp/

Then, run the  "create_map_input.R" to create the input file for the map.
